# Proyecto Grupo F - Desarrollo Web

Este proyecto incluye la configuración de Git, GitHub y automatización de procesos mediante CI/CD.

### Estructura del Proyecto:
* **.github/workflows**: Archivos de automatización (GitHub Actions).
* **css**: Carpeta para hojas de estilo.
* **js**: Carpeta para archivos JavaScript.
* **index.html**: Archivo principal del sitio.

### Integración Continua:
Se ha configurado un flujo de trabajo que se ejecuta automáticamente con cada `push` para validar el proyecto.
